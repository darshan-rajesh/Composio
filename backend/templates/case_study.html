Limitations & Honest Reporting

⚠️
Point-in-Time Data

API access, pricing, and MCP availability change frequently. Findings reflect the research date.

⚠️
AI Interpretation Limits

LLM-based extraction may misinterpret ambiguous documentation. Confidence scores reflect uncertainty.

⚠️
Search Coverage

Web search may not find recently updated documentation or private developer portals.

⚠️
MCP Ecosystem Maturity

MCP is a new standard. Many "No" results may become "Yes" as the ecosystem grows.

⚠️
Buildability Subjectivity

Buildability verdicts reflect API accessibility, not implementation complexity.

⚠️
Sample Size

100 apps across 10 categories provides directional insights but not exhaustive market coverage.

Conclusions

This automated research pipeline demonstrates that AI agents can perform scalable, verifiable SaaS research with quantified confidence levels. The multi-agent verification approach caught errors and improved accuracy, while human auditing provided ground-truth benchmarking.


Key takeaways for Composio's product operations: The SaaS integration landscape is dominated by REST APIs with OAuth2 authentication. Self-serve access is common in developer-focused categories, while enterprise categories remain gated. MCP adoption is early-stage, presenting a significant opportunity for platforms that can bridge this gap.


The pipeline architecture — CSV → Research Agent → Verification Agent → Confidence Scoring → Human Audit → Analytics — is designed to be repeatable, scalable, and honest about its limitations.
